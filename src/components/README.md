# Shared video components

Place genuinely reusable visual components here when multiple scenes or videos need them. Keep one-off components in the owning video's directory instead of building a speculative component library.

Follow [video organization](../../docs/video-organization.md) and [the visual reference](../../docs/tryslides/visual-identity.md). Review affected videos when changing a shared component so an approved production does not silently change its appearance or timing.
