# Production brief — v01

Date: 2026-10-17. Status: Draft awaiting owner approval.

## Intent

- Working title: **Build an interactive solar system lesson in TrySlides**.
- Recommended primary audience: English-speaking teachers creating visual lessons, assumed beginner level. This audience is an editorial recommendation, not a verified customer segment or an approved owner choice yet.
- Viewer need: turn a dense explanation into a readable overview with one explorable detail.
- Main message: design one clear learning path before adding effects.
- Objective: the viewer can build and test Base → Earth detail → Base.
- Treatment: result-first, voice-led practical tutorial, not an exhaustive interface tour.
- Spoken narration, captions, presentation text, titles and CTA: **English**, explicitly requested by owner. English interface capture required.
- Channel assumption: YouTube desktop long-form plus YouTube Shorts/Instagram Reels derivatives.
- Target: approximately 14 minutes, within the required 12–20 minutes; 1920 × 1080, 16:9, 30 fps. Timing is provisional until voiceover and capture inspection.
- Family: one long-form, four distinct 50-second vertical edits, one YouTube thumbnail, four vertical covers, one 1080 × 1080 post. See [deliverables](deliverables.md).
- CTA: “Save this walkthrough for your next lesson, and subscribe for the next TrySlides tutorial.” No public signup/launch promise.

## Product grounding

- Manual workflow: desktop → blank presentation → text and shapes → Base → one Step → state-specific Click interactions → Present → HTML/PDF inspection.
- Build from blank; solar-system example is not a catalog template. No MCP or external AI connection in this production.
- Presentation: Our solar system; one slide, Base and one Earth detail Step. Eight labeled planet markers; only Earth is interactive. Caption near the overview: “Click Earth to explore”.
- Scientific scope: ordered planet names and Earth as third planet from Sun. All graphics explicitly simplified; sizes/distances not to scale. No orbital animation, orbital speed or scale claims.
- Product references: [product](../../docs/tryslides/product.md), [claims](../../docs/tryslides/limits-and-claims.md), [audiovisual](../../docs/tryslides/audiovisual-direction.md), [visual identity](../../docs/tryslides/visual-identity.md).
- English product source guides inspected on 2026-10-17 in sibling `tryslides/content/docs/`: `getting-started.mdx`, `design/shapes.mdx`, `design/text.mdx`, `motion/steps.mdx`, `motion/interactions.mdx`, `motion/present.mdx`, `files/export.mdx`. This is repository evidence, NOT a deployed walkthrough verification.
- Documented account requirement: Google sign-in; no Pro-only hosted sharing needed. Owner must confirm actual environment, available controls, plan and version/date before recording.
- Proof gates: inherited Earth identity, unchanged Base, saved per-state interactions, uninterrupted round trip in Present, downloaded HTML round trip, actual static PDF.
- Publication blockers: deployed behavior and exact labels untested; footage absent; exported files uninspected. Never fabricate screen behavior to match the script.

## Visual direction

- Editorial graphics: Paper #F4F1E9, Ink #242322, Blue #4565EE; Geist. These are production recommendations, not a new brand book.
- Lesson artwork: neutral light background, dark text, Sun amber, Earth blue, other circles restrained; labels and order numbers carry meaning independently of color. Circles are illustrative markers, not scientific photography.
- Use native editable shapes and text inside TrySlides; no external photos required. Original logo/font source paths tracked in assets; no replacements invented.
- Mix actual UI/action evidence, progressive concept diagrams, captured before/after comparison, result playback and short chapter titles. No persistent idle editor background.
- Start with full context; crop controls only when teaching them, then return to the result. Vertical versions are separately reframed.
- Direct cuts for continuous work; restrained fades for chapter changes; Earth match cut to explain identity. No decorative motion on every click.

## Audio and captions

- Calm, clear English voiceover; friendly teacher-to-teacher, not a sales read. Presenter/voice provider unassigned; no synthetic voice or voice cloning authorized.
- Record after script approval and a product dry run. Separate clean narration is recommended; no microphone needed on UI recordings.
- Quiet instrumental bed is optional: light opening, low under explanations, modest lift on successful playback, resolved ending. No mandatory paid music search.
- Agent can create diagrams, captions and editorial effects after approval. License any music/effects before use; a voice-only version is valid if music is not cleared.
- Remove mistakes/repetition/accidental gaps without clipping words or eliminating natural pauses. Keep proof actions at comprehensible speed; preserve sync after cuts.
- Captions: English, synchronized from final narration, max two lines, readable contrast and no collision with UI/vertical platform controls. On-screen emphasis is not a second transcript.
