Return to the overview and select the Earth image. In Properties, use the plus button beside Interactions. Choose Click as the event and set the destination to Step 1, then save the interaction. The saved Earth interaction identifies its action as Go to Step 1. That gives us the outward route. The Step defines what we see when we arrive; the interaction defines how we get there. Those are different jobs. Now switch to Step 1 and select the Back text. Give it a Click interaction that returns to Base, and save it. Configure the return on the Back element in the detail state, not on an unrelated element in the overview. Interactions belong to their state, so check both directions rather than assuming that one setting completes the whole journey. Our example uses clicks, with a visible return control. We are not relying on hover as the only way to explore. Once the settings are saved, test the route in presentation mode. Selecting objects in the editor is not the same as following their interactions during playback.
