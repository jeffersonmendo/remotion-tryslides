Start in the desktop editor and create a new blank presentation. Name it Our Solar System. We are starting from scratch because seeing the structure take shape is useful for this lesson. This is a manually built example, not a ready-made solar-system template. The slide canvas is where the content lives. The slide navigation keeps track of the presentation, and the properties panel gives us controls for the selected element. Those are the areas we need first. Add the heading Our Solar System, then place a shorter question underneath: Where is Earth? The heading identifies the subject; the question gives the viewer something to find. Keep both inside the slide boundaries. Now choose the Dark presentation theme. The slide becomes black, with contrasting light text. This changes the presentation theme, not just the editor appearance. The dark backdrop is a choice for this lesson, not a requirement for every presentation. We will check the finished composition in presentation mode later.
